# Reglas de reescritura independiente

## Principio

La implementación se desarrollará desde cero a partir de requisitos,
documentación pública, respuestas de las fuentes de datos y observación
del comportamiento del mapa actualmente desplegado.

## No permitido

- Copiar archivos del repositorio anterior.
- Copiar fragmentos de Python, JavaScript, HTML, CSS, Compose o Nginx.
- Trasladar código cambiando únicamente nombres o formato.
- Usar el diff del repositorio anterior como guía de implementación.
- Incluir código de terceros sin comprobar antes su licencia.

## Permitido

- Reutilizar requisitos funcionales e ideas generales.
- Consultar documentación pública de protocolos y bibliotecas.
- Analizar respuestas JSON de las fuentes de datos.
- Comparar el comportamiento visible de ambos mapas.
- Usar bibliotecas con licencias compatibles conservando sus avisos.
- Volver a implementar algoritmos y estructuras de forma independiente.

## Proyecto anterior

`/srv/meshtastic-map` permanece como servicio en producción y referencia
visual privada. No se copiará su implementación al nuevo repositorio.
